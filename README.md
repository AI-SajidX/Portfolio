## Overview

This portfolio is designed to present my background as a Computer Science and Engineering undergraduate, my technical interests, and the projects I have developed throughout my learning journey.

Built with a modern frontend stack, it features a dark visual theme, glassmorphism-inspired interface, smooth scrolling, and interactive animations to deliver an engaging browsing experience.

The website serves as a central place to explore my work, technologies, skills, education, and contact information.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern dark-themed interface
- Glassmorphism-inspired UI elements
- Smooth scrolling experience
- GSAP-powered scroll animations
- Framer Motion interactions
- Animated hero section
- Dedicated About, Skills, Tech Stack, and Education sections
- Featured project showcase with repository links
- Contact section and social links
- Reusable component-based architecture

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/AI-SajidX/SajidX-Portfolio.git
```

Navigate to the project directory:

```bash
cd SajidX-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## Production Build

To build the project for production:

```bash
npm run build
```

## Deployment

The portfolio is deployed on Vercel.

**Live URL:** [ai-sajid-portfolio.vercel.app](https://ai-sajid-portfolio.vercel.app/)

The project is connected to GitHub for continuous deployment. Changes pushed to the configured branch trigger a new deployment automatically.
